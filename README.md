
# 👗 StyleThrift

StyleThrift is a modern fashion e-commerce website designed to showcase trendy clothing and accessories. It provides a clean and user-friendly interface for browsing products and simulates an online shopping experience.

---

## 🚀 Features

- 🛍️ Browse fashion products
- 📂 Category-based product sections
- 💻 Responsive design (works on mobile & desktop)
- 🔐 Basic login page (no authentication validation yet)
- 🎨 Clean and modern UI

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
